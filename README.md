# DevOps Server Monitoring Toolkit

A beginner-friendly DevOps project that monitors Linux system resources and Docker containers using Bash scripts.

## Technologies

- Linux
- Bash Shell Scripting
- Git
- Docker
- Docker Compose

## Project Structure

```
devops-server-monitor/
├── scripts/
├── reports/
├── logs/
├── Dockerfile
├── docker-compose.yml
├── README.md
└── .gitignore
```

## Features (Planned)

- System Information
- CPU Monitoring
- Memory Monitoring
- Disk Monitoring
- Network Monitoring
- Docker Monitoring
- Health Report Generation
- Cron Automation
